# PFxamd Brand Assets

Canonical storage for original PFxamd brand files used in PFxamd projects.

## Current assets

| Asset | Path |
| --- | --- |
| Official logo | [`logos/logo.svg`](logos/logo.svg) |

The official brand name and current asset paths are recorded in [`brand.json`](brand.json).

## Use in a project

Retrieve the required file from this repository and copy it into the project's own assets folder. After copying, the project does not need to access this repository. See [`AGENTS.md`](AGENTS.md) for agent instructions.

## Future assets

Add additional logo variants under `logos/`, icons under `icons/`, fonts under `fonts/`, and other visual assets under `graphics/` as they become available. Update `brand.json` with approved paths when adding assets. No folders or entries are needed before a file exists.

Original brand assets are not granted an open-source license by being published in this repository.
